# 리센느 덕질 위키 (S06 예시 볼트)

S06 시즌2 킥오프의 옵시디언 파트에서 현장에 직접 열어 보이는 예시 볼트다. 덕질 위키를 만드는 사람의 볼트라는 설정이고, 나무위키·위키백과 수준의 읽을 만한 품질을 목표로 했다. 세션 맥락은 NUGI-Core의 `02_sessions/S06-시즌2킥오프/`에 있다.

## 여는 법

1. Obsidian을 켜고 「볼트 관리」 화면에서 「폴더를 볼트로 열기」를 고른다.
2. 이 폴더(`rescene-vault`)를 선택한다. `.obsidian/` 설정이 같이 있어 테마와 스니펫이 그대로 적용된다.
3. 처음 열면 「제한 모드 끄기」를 묻는다. 커뮤니티 플러그인이 없으니 켜지 않아도 된다.
4. 시작 노트는 `00 대문/리센느.md`, 안내는 `00 대문/둘러보기 길잡이.md`.

## 구조

| 폴더 | 내용 |
|---|---|
| 00 대문 | 대문, 둘러보기 길잡이, 볼트 설계서 |
| 10 멤버 | 멤버 노트 5개와 멤버 목록 Base |
| 20 디스코그래피 | 앨범 노트와 곡 디스코그래피 Base |
| 30 무대와 콘텐츠 | 무대·콘텐츠 노트 |
| 40 콘셉트와 세계관 | 그룹명, 향기 콘셉트 |
| 50 타임라인 | 연도별 활동, 활동 연표, 컴백 타임라인 Canvas |
| 90 템플릿 | 멤버, 앨범, 곡 템플릿 |
| 99 참고 | 출처 |

규칙과 속성 정의는 `00 대문/볼트 설계.md`가 정본이다. 문장 속 링크만 쓰고, 멤버 노트는 참여곡을 직접 나열하지 않고 백링크와 Base가 모은다.

## 세팅

| 항목 | 값 |
|---|---|
| 테마 | Prism 3.8.0 (`.obsidian/themes/Prism`, 로컬 복사), 다크, 포인트 색 `#b983ff`, 글자 17 |
| 스니펫 | `MCL Gallery Cards`, `rescene-infobox`, `rescene-hero`, `rescene-callouts`, `rescene-nobanner`(Prism이 Style Settings 플러그인 없이 띄우는 빨간 안내 배너를 숨김) (`.obsidian/snippets/`) |
| 커뮤니티 플러그인 | 없음. Bases, Canvas, 그래프, 백링크는 코어 |
| 속성 | `type`, `source`(공식/2차/내 생각), `확인`(확정/확인 필요) 등 |

## 확인 필요 목록

사실 정보는 전부 2차 출처 기준이고 공식 채널을 직접 확인하지 못했다(리서치 R15). 속성 `확인: "확인 필요"`인 노트에는 본문에 `> [!warning] 확인 필요` 박스가 있다. 목록은 볼트 안에서 검색 `[property:확인:"확인 필요"]` 로 보거나 터미널에서 다음으로 센다.

```bash
grep -rl '^확인: "확인 필요"' . --include='*.md'
```

그 밖의 미결: River의 한 줄 칸 25개가 비어 있다(사람 손 규칙). 이미지는 공식 아트워크 사용 범위를 확인하지 못해 넣지 않았다. 사생활성 정보는 넣지 않았다. Obsidian에서의 렌더는 2026-11-08 기준 미확인이다. 리허설에서 그래프, Canvas, Base, 테마를 확인한다.

## zip 배포

현장에서 회원에게 나눠 줄 때는 `.obsidian`을 포함해 압축한다. macOS 기준:

```bash
cd <볼트 폴더들이 들어 있는 상위 폴더>
zip -r rescene-vault.zip rescene-vault -x '*/Icon*' -x '*/.DS_Store'
```

받은 사람은 압축을 풀고 위 「여는 법」대로 연다. 볼트는 iCloud 폴더 밖 로컬(바탕화면, 문서)에 둔다. 안드로이드는 「기기 저장소」를 고른다.
