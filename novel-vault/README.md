# 종탑 도시 오르넬 (S06 예시 볼트)

S06 시즌2 킥오프의 옵시디언 파트에서 현장에 열어 보이는 예시 볼트다. 웹소설 연재를 준비하는 지망생 「물빛」(필명, 가상)이 세계관과 원고를 한곳에서 관리한다는 설정이다.

> **가상 안내** 도시, 인물, 사건, 기술 규칙은 모두 오리지널 가상 설정이다. 실존 작품이나 인물과 관계가 없다. 원고 속 글자수와 완성도 수치는 연습용 가상 값이고, 초고는 발췌만 실었다.

## 처음 볼 곳 3곳

1. `00 대문/대문.md` 세계관 개요와 줄거리 한 줄
2. `10 인물/인물 표.base` 인물 8명을 표로 보고 소속별로 묶어 본다
3. `60 지도/인물 관계도.canvas` 인물 사이 관계를 선으로 본다. 이어서 `50 연재/회차 진행 표.base`도 열어 본다

## 여는 법

1. Obsidian을 켜고 「볼트 관리」 화면에서 「폴더를 볼트로 열기」를 고른다.
2. 이 폴더(`novel-vault`)를 선택한다. `.obsidian/` 설정이 같이 있어 테마와 스니펫이 그대로 적용된다.
3. 처음 열면 「제한 모드 끄기」를 묻는다. 커뮤니티 플러그인이 없으니 켜지 않아도 된다.

## 구조

| 폴더 | 내용 |
|---|---|
| 00 대문 | 대문, 연재 계획, 볼트 설계 |
| 10 인물 | 인물 노트 8개와 인물 표(Bases) |
| 20 장소와 세력 | 도시, 건물, 조직 노트 7개 |
| 30 설정 | 풍종 공명 규칙, 종소리의 대가, 안개열, 용어집, 세계관 일관성 점검 |
| 40 플롯 | 3막 구조, 회차 아웃라인, 복선 목록 |
| 50 연재 | 1화부터 5화 초고(발췌)와 회차 진행 표(Bases) |
| 60 지도 | Canvas 2개 (인물 관계도, 사건 타임라인) |
| 90 템플릿 | 인물, 장소, 회차 템플릿 |

규칙과 속성 정의는 `00 대문/볼트 설계.md`가 정본이다.
