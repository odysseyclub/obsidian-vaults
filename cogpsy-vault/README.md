# 인지심리학 개념 위키 (S06 예시 볼트)

S06 시즌2 킥오프의 옵시디언 파트에서 현장에 직접 열어 보이는 예시 볼트다. 시험을 준비하는 심리학과 학부생이 개념을 한 화면으로 훑는 볼트라는 설정이다. 세션 맥락은 NUGI-Core의 `02_sessions/S06-시즌2킥오프/`에 있다.

## 여는 법

1. Obsidian을 켜고 「볼트 관리」 화면에서 「폴더를 볼트로 열기」를 고른다.
2. 이 폴더(`cogpsy-vault`)를 선택한다. `.obsidian/` 설정이 같이 있어 테마와 스니펫이 그대로 적용된다.
3. 처음 열면 「제한 모드 끄기」를 묻는다. 커뮤니티 플러그인이 없으니 켜지 않아도 된다.
4. 시작 노트는 `00 시작/시작하기.md`.

## 구조

| 폴더 | 내용 |
|---|---|
| 00 시작 | 시작하기, 볼트 설계서 |
| 10 개념 | 개념 노트 17개와 개념 표 |
| 20 학자 | 학자 노트 5개 |
| 30 연구 | 고전 실험과 논문 노트 13개 |
| 40 강의 | 주차 노트 4개 |
| 50 지도 | Canvas 1개 (시험 전 개념 지도) |
| 90 템플릿 | 개념, 연구, 강의 템플릿 |
| 99 참고 | 출처 |

규칙과 속성 정의는 `00 시작/볼트 설계.md`가 정본이다. 링크 관계는 포함, 대조, 발전, 근거 네 가지를 문장으로 쓴다.

## 세팅

| 항목 | 값 |
|---|---|
| 테마 | Minimal 9.0.2 (`.obsidian/themes/Minimal`, 로컬 복사), 라이트, 포인트 색 `#4c7df0`, 글자 17 |
| 스니펫 | `cogpsy-concept`, `cogpsy-canvas` (`.obsidian/snippets/`) |
| 커뮤니티 플러그인 | 없음 (`community-plugins.json`이 빈 목록). Bases, Canvas, 그래프, 백링크, 템플릿은 코어 |
| 속성 | `type`, `분야`, `제안자`, `연도`, `주차`, `source`(AI/내 생각) |
| 그래프 | 폴더별 색 (개념 파랑, 학자 주황, 연구 초록, 강의 보라), 태그 노드 끔 |

## 확인 필요 목록

서지의 일부(출판사, 원문 대조 전 2차 출처)를 확인하지 못했다(리서치 R19). 해당 노트는 본문에 `> [!warning] 확인 필요` 박스가 있고, 연구 노트는 속성 `서지확인: "확인 필요"`가 있다. 터미널에서 세는 법:

```bash
grep -rl '확인 필요' . --include='*.md'
```

원문 대조 전의 해석은 문장 끝에 「(제안)」이 붙어 있다. 「내 말로 쓴 정의」와 「헷갈린 점」은 사람 손으로 채울 칸이다. Obsidian에서의 렌더는 2026-11-08 기준 미확인이다. 리허설에서 그래프, Canvas, 개념 표, 테마를 확인한다.

## zip 배포

현장에서 회원에게 나눠 줄 때는 `.obsidian`을 포함해 압축한다. macOS 기준:

```bash
cd <볼트 폴더들이 들어 있는 상위 폴더>
zip -r cogpsy-vault.zip cogpsy-vault -x '*/Icon*' -x '*/.DS_Store'
```

받은 사람은 압축을 풀고 위 「여는 법」대로 연다. 볼트는 iCloud 폴더 밖 로컬(바탕화면, 문서)에 둔다. 안드로이드는 「기기 저장소」를 고른다.
