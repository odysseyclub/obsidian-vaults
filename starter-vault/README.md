# 옵시디언 스타터 볼트 (S06 예시 볼트)

내우주기 S06 세션에서 회원이 오늘 처음 여는 가벼운 볼트다. 옵시디언을 처음 만나는 사람이 설치부터 링크, 속성, 템플릿까지 눌러 보도록 짰다. 등장하는 AI 활용 카드 사례는 전부 가상이다.

## 처음 볼 곳 3곳

1. `00 시작/시작하기.md` 설치, 볼트 열기, 안드로이드, 제한 모드
2. `20 연습/링크 연습.md` 위키링크, 백링크, 별칭, 임베드 과제
3. `10 카드/카드 예시 1 발표 개요 잡기.md` 채워진 AI 활용 카드 한 장

## 여는 법

1. Obsidian을 켜면 나오는 시작 화면에서 「보관함 폴더 열기」 줄의 「열기」를 누른다. (한국어 앱에서 볼트는 「보관함」으로 표시된다. 이미 열려 있으면 왼쪽 아래 보관함 이름, 「보관함 관리하기...」)
2. 이 폴더(`starter-vault`)를 골라 「열기」를 누른다.
3. 「제한 모드 끄기」를 묻는 창이 뜰 수 있다. 커뮤니티 플러그인이 없으니 끄지 않아도 된다.
4. 볼트 폴더는 iCloud, Google Drive 같은 동기화 폴더 밖에 둔다.

## 구조

| 폴더 | 내용 |
|---|---|
| 00 시작 | 시작하기, 내 첫 노트 |
| 10 카드 | AI 활용 카드 예시 2장, 카드 표(Bases) |
| 20 연습 | 링크 연습, 연습용 노트 2개, 속성 연습 |
| 90 템플릿 | AI 활용 카드 템플릿 |

노트는 9개이고 Bases 1개(`10 카드/카드 표.base`)가 있다.

## 세팅

| 항목 | 값 |
|---|---|
| 테마, 스니펫 | 없음 (옵시디언 기본) |
| 플러그인 | 코어만. 템플릿 폴더는 `90 템플릿` |
| 속성 | `title`, `status`, `created`, `type` 기본, 카드는 `도구` 추가 |
| 그래프 | 폴더별 색, 태그 노드 끔 |

## 가상 설정과 확인 필요

- 카드 예시 2장과 연습 노트의 사례는 가상이다. 카드 안에 「가상 예시임」 표기가 있다.
- 안드로이드 앱의 화면 문구는 확인하지 못했다. `시작하기.md`에 「화면 문구가 다를 수 있음」이라고 적어 두었다.
- 옵시디언에서의 실제 렌더(템플릿 삽입, 임베드, Bases 표)는 미확인이다. 리허설에서 확인한다.
- 사람이 채울 칸은 `> [!note]` 박스로 비워 두었다. `내 첫 노트.md`, 템플릿의 8칸이 해당한다.

## zip 배포

```bash
cd <볼트 폴더들이 들어 있는 상위 폴더>
zip -r starter-vault.zip starter-vault -x '*/Icon*' -x '*/.DS_Store'
```
