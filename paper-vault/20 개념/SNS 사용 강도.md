# SNS 사용 강도

> SNS 사용 강도는 소셜미디어를 얼마나 자주, 오래, 깊이 쓰는지를 하나의 변인으로 모은 것이다.

## 정의

SNS 사용 강도는 소셜미디어를 얼마나 자주, 오래, 깊이 쓰는지를 하나의 변인으로 모은 것이다. 졸업논문에서는 아래 뜻으로 쓴다고 정해 두었다.

> [!point] 논점 카드
> 사용 강도를 시간 하나로 정의할지 여러 지표의 합으로 정의할지가 이 논문의 첫 번째 결정이다.

## 핵심 내용

시간만 재는 방법, 하루 확인 횟수를 재는 방법, 정서적 몰입을 묻는 방법이 섞여 쓰인다.[^1] 이 논문에서는 시간과 확인 횟수 두 가지를 기본으로 하고, 정서적 몰입은 가상 척도로 보조한다고 가정했다. 자세한 정리는 [[변인 정리]]에 있다. 스스로 보고한 시간은 실제와 다를 수 있어 [[자기보고 편향]]을 함께 적어 둔다.

## 관련 문헌

[[한서윤 2021(가상)]]이 사용 시간을, [[문지호 2022(가상)]]가 사용 직후라는 시점을 중심으로 다룬다. [[Przybylski 2017]]은 사용량과 결과의 관계가 직선이 아닐 수 있음을 알려 준다.

## 헷갈리는 개념

[[미디어 멀티태스킹]]과 구분한다. 또 스마트폰 근접([[Ward 2017]])은 기기가 곁에 있는 문제라 사용 강도와 다르다.
