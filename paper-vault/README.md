# 졸업논문 문헌 정리 볼트 (S06 예시 볼트)

S06 시즌2 킥오프의 옵시디언 파트에서 직접 열어 보이는 예시 볼트다. 심리학과 3학년 「다온」이 「소셜미디어 사용과 주의 지속」이라는 졸업논문 주제로 문헌을 정리하는 볼트라는 설정이다.

> **가상 설정 안내.** 다온이라는 인물, 연구 설계, 척도, 표본, 지도교수는 모두 가상이다. 문헌 노트 중 파일명에 「(가상)」이 붙은 3편은 지어낸 논문이다. 나머지 6편은 실존하는 논문이지만 저자, 연도, 큰 주장만 일반상식 수준으로 적었고 권호와 쪽수는 비워 두었다. 인용하기 전에 원문을 확인해야 한다.

## 처음 볼 곳 3곳

1. `00 대문/대문.md` : 논문 로드맵과 연구 질문, 문헌 표 미리보기
2. `50 지도/선행연구 지도.canvas` : 읽은 논문들이 어떻게 이어지는지 Canvas로 본다
3. `10 문헌노트/문헌 표.base` : 연도, 읽음 상태, 관련 변인으로 정렬되는 표

## 여는 법

1. Obsidian을 켜고 「볼트 관리」 화면에서 「폴더를 볼트로 열기」를 고른다.
2. 이 폴더(`paper-vault`)를 선택한다. `.obsidian/` 설정이 같이 있어 테마와 스니펫이 그대로 적용된다.
3. 「제한 모드 끄기」를 묻는다면 켜지 않아도 된다. 커뮤니티 플러그인을 쓰지 않는다.
4. 볼트는 iCloud 폴더 밖 로컬(바탕화면, 문서)에 둔다.

## 세팅

| 항목 | 값 |
|---|---|
| 테마 | Soft Paper 1.2.2 (`.obsidian/themes/Soft Paper`, 로컬 복사), 라이트, 포인트 색 `#a8754f`, 글자 17 |
| 스니펫 | `paper-callouts` (인용 블록 `[!cite]`, 논점 카드 `[!point]`), `paper-notes` (속성 상자, 제목, 초고 줄 종이) |
| 플러그인 | 커뮤니티 플러그인 없음. Bases, Canvas, 그래프, 템플릿은 코어 기능 |
| Zotero | 연동 플러그인을 설치하지 않는다. 손으로 복사하는 방식 (`60 인용과 Zotero`) |
| 그래프 | 폴더별 색, 태그 노드 끔 |

## 확인 필요 목록

문헌 노트의 실존 논문 6편은 권호, 쪽수, 후속 재현 결과를 확인하지 못했다. 해당 노트에는 `> [!warning] 확인 필요` 박스가 있다. 표본 크기, 척도 이름, 신뢰도도 확인하지 않은 가상 값이다. 터미널에서 세는 법:

```bash
grep -rl '확인 필요' . --include='*.md'
```

「River 한 줄 (비워 둠)」 박스는 사람이 채우는 칸이다. Obsidian에서의 실제 렌더(테마, 콜아웃, Bases, Canvas)는 아직 직접 확인하지 않았다. 리허설에서 확인한다.

## zip 배포

```bash
cd <볼트 폴더들이 들어 있는 상위 폴더>
zip -r paper-vault.zip paper-vault -x '*/Icon*' -x '*/.DS_Store'
```
