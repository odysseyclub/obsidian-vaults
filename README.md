# 내우주기 옵시디언 볼트 모음

내우주기(內宇宙記) 시즌2 킥오프(S06)에서 쓰는 옵시디언 예시 볼트 6개와 처음 시작하는 사람용 스타터 볼트 1개입니다. 전부 열어서 클릭하며 놀 수 있게 만들었습니다. 인물, 일기, 논문 결과는 가상이거나 연습용이고, 확인하지 못한 사실에는 `확인 필요` 표시가 붙어 있습니다.

## 받는 법

**방법 A. 한 번에 받기.** 이 페이지 위쪽 초록색 `Code` 버튼, `Download ZIP`. 압축을 풀면 볼트 7개 폴더가 나옵니다.

**방법 B. 볼트 하나만 받기.** [Releases](../../releases)의 `s06-2026-11-09`에서 원하는 `*.zip` 하나만 받아 압축을 풉니다.

**열기.** 옵시디언을 실행하고(없으면 https://obsidian.md/download ) 「볼트 관리」 화면에서 **폴더를 볼트로 열기**를 누른 뒤, 압축 푼 볼트 폴더(예: `daily-vault`)를 고릅니다. `.obsidian` 설정이 같이 있어 테마와 스니펫이 그대로 적용됩니다.

- 볼트 폴더는 iCloud, 구글 드라이브 같은 동기화 폴더 밖(바탕화면, 문서)에 두세요.
- 안드로이드는 기기 저장소 아래 폴더에 풀어 두고 앱에서 같은 방식으로 엽니다.
- 「제한 모드를 끌까요?」는 묻지 않으면 그대로 두면 됩니다. 이 볼트들은 커뮤니티 플러그인 없이 코어 기능만 씁니다.
