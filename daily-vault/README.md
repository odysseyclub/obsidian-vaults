# 한결의 하루 볼트 (S06 예시 볼트, 가상)

하루를 짧게 기록하며 습관을 만들어 가는 대학생 「한결」의 볼트다. 한결과 일기는 모두 세션을 위해 만든 가상이며 실제 인물의 기록이 아니다. 2026년 10월 중 15일치 일기, 주간회고 3개, 월간요약 1개가 들어 있다.

## 처음 볼 곳 3곳

1. `50 지도/습관 표.base` : 일기의 속성(수면, 운동, 독서, 기분)이 표와 카드로 모이는 모습
2. `10 데일리/2026-10-14.md` : 데일리 노트 한 장의 모양
3. `50 지도/한 달 흐름 지도.canvas` : 일에서 주, 주에서 월로 접어 올리는 흐름

그 뒤에 `00 대문/대문.md`를 읽으면 전체 길이 잡힌다.

## 여는 법

1. Obsidian을 켜고 「볼트 관리」에서 「폴더를 볼트로 열기」를 고른다.
2. 이 폴더(`daily-vault`)를 선택한다. `.obsidian/` 설정이 같이 있어 테마와 스니펫이 그대로 적용된다.
3. 「제한 모드 끄기」를 묻는다. 커뮤니티 플러그인이 없으니 켜지 않아도 된다.
4. 시작 노트는 `00 대문/대문.md`. 볼트는 iCloud 폴더 밖 로컬에 둔다.

## 테마와 스니펫

| 항목 | 값 |
|---|---|
| 테마 | AnuPpuccin 1.5.0 (`.obsidian/themes/AnuPpuccin`, 로컬 복사), 라이트 파스텔, 포인트 색 연보라 `#a78bda`, 글자 17 |
| 스니펫 | `haru-tags`(기분 태그를 파스텔 알약으로), `haru-daily`(한 줄 인용 카드, 둥근 체크박스, 속성 상자) |
| 코어 플러그인 | 파일 탐색기, 검색, 그래프, 백링크, 캔버스, 속성, 베이스, 템플릿, 일일 노트 등 |
| 일일 노트 | 폴더 `10 데일리`, 형식 `YYYY-MM-DD`, 템플릿 `90 템플릿/tpl-데일리` (`.obsidian/daily-notes.json`) |

## 구조

| 폴더 | 내용 |
|---|---|
| 00 대문 | 대문(오늘 보는 법), 볼트 설계, 개발자의 한 줄 |
| 10 데일리 | 2026-10 가상 일기 15개 |
| 20 주간 | 주간회고 3개 (W41~W43) |
| 30 월간 | 월간요약 1개 (프랙탈 저널 설명 포함) |
| 40 습관 | 운동, 수면, 독서, 공부 습관 설명 노트 |
| 50 지도 | 습관 표(.base), 주간 모아보기(.base), 한 달 흐름 지도(.canvas) |
| 90 템플릿 | 데일리, 주간, 월간 |

설계 규칙은 `00 대문/볼트 설계.md`가 정본이다.

## 가상 설정과 확인 필요

- 모든 인물, 날짜별 기록, 수치는 가상이다. 한글날(10월 9일)이 금요일이라는 정도의 달력 사실만 실제와 맞춘다.
- `개발자의 한 줄`과 각 주간회고, 월간요약의 `한결의 한 줄`은 사람이 채울 빈칸이다.
- Obsidian에서의 렌더(Bases 합계 행, 카드 보기, 태그 색, AnuPpuccin의 체크박스 모양)는 아직 실제로 열어 확인하지 못했다. 리허설에서 확인한다.
