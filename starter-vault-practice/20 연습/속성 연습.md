# 속성 연습

이 노트 맨 위에 표로 보이는 칸이 속성(frontmatter)이다. 노트에 이름표를 붙이는 기능이다.

## 해 볼 것

1. 위쪽 속성에서 `status`를 `draft`에서 `live`로 바꿔 본다.
2. `다 했나`의 체크 표시를 눌러 켠다.
3. 속성 추가 버튼으로 `메모`라는 새 속성을 만들고 글자를 넣는다.
4. 왼쪽 파일 목록에서 [[카드 표.base]]를 열어 `10 카드` 폴더 노트들의 속성이 표로 모이는 것을 본다.

속성을 잘 맞춰 두면 Bases가 이 값으로 표를 만든다. 카드 노트를 직접 쓸 때도 [[AI 활용 카드 템플릿]]이 속성을 미리 넣어 준다.
