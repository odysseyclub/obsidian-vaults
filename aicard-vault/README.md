# AI 사용 카드 모음 (S06 예시 볼트)

> [!warning] 가상 설정
> 이 볼트는 가상이다. 동아리에서 AI 활용 사례를 카드로 모아 공유하는 운영팀과 회원이 쓰는 볼트라는 설정이고, 카드 속 사례와 작성자 별명은 모두 지어낸 것이다.

S06 시즌2 킥오프 세션 3부 「AI 공유회」에서 보여 줄 예시 볼트다. 카드 한 장에 목적, 도구, AI 없이 내가 먼저 한 것, 입력, 프롬프트, 결과, 확인 방법, 팁을 적는다. 프롬프트는 직접 쓴 예시이고 AI 응답은 「가상 예시 출력」으로 표시했다.

## 처음 볼 곳

1. `00 대문/대문.md` : 볼트 소개와 카드 갤러리(Bases 임베드)
2. `10 카드/과제 자료 정리.md` : 가장 쉬운 카드 한 장
3. `40 지도/카드 지도.canvas` : 카드를 목적별로 묶은 지도

## 여는 법

1. Obsidian을 켜고 「볼트 관리」 화면에서 「폴더를 볼트로 열기」를 고른다.
2. 이 폴더(`aicard-vault`)를 선택한다. `.obsidian/` 설정이 같이 있어 테마와 스니펫이 그대로 적용된다.
3. 처음 열면 「제한 모드 끄기」를 묻는다. 커뮤니티 플러그인이 없으니 켜지 않아도 된다.

## 구조

| 폴더 | 내용 |
|---|---|
| 00 대문 | 대문, 카드 쓰는 법, 볼트 설계 |
| 10 카드 | 가상 사례 카드 17장, Bases 2개(카드 갤러리, 도구별 표) |
| 20 도구 | ChatGPT, Claude, Gemini, NotebookLM, Perplexity |
| 30 원칙 | AI 없이 먼저 하기, 검증하기, 출처 표기, 개인정보 넣지 않기 |
| 40 지도 | Canvas 1개와 해설 노트 |
| 90 템플릿 | 카드 템플릿 |

규칙과 속성 정의는 `00 대문/볼트 설계.md`가 정본이다.

## 세팅

| 항목 | 값 |
|---|---|
| 테마 | Things (`.obsidian/themes/Things`, 로컬 복사), 라이트, 포인트 색 `#2b7de9`, 글자 16 |
| 스니펫 | `aicard-callout`(프롬프트 박스, 확인 방법 박스, 가상 예시 출력 박스), `aicard-card`(속성 칸과 제목 정돈) |
| 커뮤니티 플러그인 | 없음. Bases, Canvas, 그래프, 백링크, 템플릿은 코어 |
| 속성 | `type`, `목적`, `도구`, `난이도`, `작성자` |
| 그래프 | 폴더별 색 (카드 파랑, 도구 주황, 원칙 초록, 지도 보라) |

## 확인 필요 목록

도구의 가격, 이용 한도, 최신 기능, 데이터 저장 설정은 쓰지 않았고 도구 노트와 원칙 노트에 `> [!warning] 확인 필요` 박스로 표시했다. 터미널에서 세는 법은 다음과 같다.

```bash
grep -rl '확인 필요' . --include='*.md'
```

「River 한 줄 (비워 둠)」 칸은 사람이 채울 자리다. Obsidian에서의 렌더(Things 테마 위의 콜아웃 색, Bases 카드 뷰, 대문의 임베드)는 2026-11-08 기준 직접 확인하지 못했다. 리허설에서 확인한다.

## zip 배포

macOS 기준:

```bash
cd <볼트 폴더들이 들어 있는 상위 폴더>
zip -r aicard-vault.zip aicard-vault -x '*/Icon*' -x '*/.DS_Store'
```

받은 사람은 압축을 풀고 위 「여는 법」대로 연다. 볼트는 iCloud 폴더 밖 로컬에 둔다.
