# 카드 쓰는 법

카드 한 장은 한 가지 상황에서 AI를 쓴 기록이다. 다음에 같은 상황을 만난 다른 사람이 5분 안에 따라 할 수 있으면 잘 쓴 카드다.

## 여덟 칸

| 칸 | 무엇을 쓰나 |
|---|---|
| 목적 | 무엇을 하려고 했는지 한두 문장 |
| 도구 | 어떤 AI를 왜 골랐는지 |
| AI 없이 내가 먼저 한 것 | AI를 열기 전에 내 손으로 한 일 |
| 입력 | AI에게 준 자료와 그 범위 |
| 프롬프트 | 실제로 쓴 요청문 |
| 결과 | AI가 준 것 (예시 카드는 「가상 예시 출력」으로 표시) |
| 확인 방법 | 틀릴 수 있는 지점과 확인한 방법 |
| 팁 | 다음에 쓸 사람에게 한마디 |

## 순서가 중요한 이유

세 번째 칸을 비우는 카드는 받지 않는다. [[AI 없이 먼저 하기]]를 건너뛰면 AI의 답이 맞는지 판단할 기준이 내게 없기 때문이다. 다섯 번째 칸 프롬프트는 길어도 괜찮다. 그대로 복사해 쓸 수 있어야 하기 때문이다.

일곱 번째 칸 확인 방법은 가장 중요하다. 「AI가 틀릴 수 있으니 확인한다」처럼 쓰지 말고, 무엇을 어떻게 확인하는지 구체적으로 쓴다. 예시는 [[영어 논문 요약 검산]]에서 볼 수 있다. 확인하는 방식은 [[검증하기]]에 모아 두었다.

## 박스 두 개

프롬프트와 확인 방법은 눈에 띄는 박스로 쓴다. 템플릿에 이미 들어 있으니 그대로 쓰면 된다.

> [!prompt] 프롬프트 박스
> 이렇게 `[!prompt]`로 시작하는 박스에 요청문을 적는다.

> [!check] 확인 방법 박스
> 이렇게 `[!check]`로 시작하는 박스에 틀릴 수 있는 지점을 번호로 적는다.

## 속성

노트 맨 위의 속성 칸에는 목적, 도구, 난이도를 꼭 적는다. 이 세 개가 있어야 [[카드 갤러리.base|카드 갤러리]]와 [[도구별 표.base|도구별 표]]가 카드를 분류한다. 난이도는 쉬움, 보통, 어려움 중에서 고른다. 처음 카드는 [[카드 템플릿]]에서 복사해 시작한다.
