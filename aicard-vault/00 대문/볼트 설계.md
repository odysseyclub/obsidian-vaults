# 볼트 설계

이 볼트가 어떻게 짜여 있는지 기록한 문서다. 새 동아리에 옮길 때 이 틀을 복사한다. 가상 설정이며 페르소나는 동아리에서 AI 활용 사례를 카드로 모아 공유하는 운영팀과 회원이다.

## 폴더

| 폴더 | 들어가는 것 | 노트 수 |
|---|---|---|
| 00 대문 | 대문, 카드 쓰는 법, 볼트 설계 | 3 |
| 10 카드 | 가상 사례 카드 17장과 Bases 2개 | 17 |
| 20 도구 | 도구별 성격 노트 | 5 |
| 30 원칙 | 네 가지 원칙 | 4 |
| 40 지도 | 카드 지도(Canvas)와 지도 해설 | 1 |
| 90 템플릿 | 카드 템플릿 | 1 |

## 속성

| 유형 | 속성 |
|---|---|
| 카드 | type, 목적, 도구, 난이도, 작성자 |
| 도구 | type, 회사, 성격 |
| 원칙 | type, 한 줄 |
| 안내 | type |

공통으로 title, status, created를 쓴다. 상태는 draft, live, archived 세 가지다. 작성자는 가상 별명이다.

## 링크 규칙

링크는 본문 문장 속에서 건다. 카드에서 도구 노트로, 카드에서 원칙 노트로, 카드에서 다음 단계 카드로 이어진다. 예를 들어 [[통계 결과 해석 보조]]는 문장 안에서 [[엑셀 함수 찾기]]로 연결된다. 목록에 링크만 모아 두지 않는다.

## 디자인 원칙

테마는 Things 라이트를 로컬로 복사해 썼다. 두 개의 스니펫이 카드 모양을 만든다. `aicard-callout`은 프롬프트 박스(파란색), 확인 방법 박스(초록색), 가상 예시 출력 박스(점선 회색)를 만든다. `aicard-card`는 속성 칸을 카드 머리글처럼 보이게 하고 섹션 제목을 정돈한다. 색은 세 가지 역할에만 쓴다. 파랑은 사람이 쓴 것, 초록은 사람이 확인한 것, 회색은 AI의 가상 출력이다.

## 그래프

폴더별로 색을 준다. 카드 파랑, 도구 주황, 원칙 초록, 지도 보라, 대문과 템플릿 회색이다. 태그 노드는 껐다.

## 가상 설정과 확인 필요

이 볼트의 카드, 작성자, 사례는 모두 가상이다. 도구의 가격과 최신 기능은 쓰지 않았고 필요한 곳에 「확인 필요」를 붙였다. 쓰는 사람은 [[대문]]에서 시작한다.
